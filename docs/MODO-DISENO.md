# Método: Modo Diseño — Kuri Fashion

Cada prototipo es una exploración visual independiente, diseñada para poder evaluarse, comparar alternativas y reutilizar lo mejor.

## Flujo de trabajo

1. **Investigación:** revisar referencias y precisar qué interacciones y decisiones compositivas resultan interesantes.
2. **Dirección artística:** buscar un lenguaje visual propio, sin repetir plantillas genéricas.
3. **Prototipo:** construir una experiencia funcional con diseño responsive.
4. **Validación:** comprobar escritorio y móvil, funcionamiento, superposición, accesibilidad y posibles errores.
5. **Archivo:** documentar hallazgos y conservar la versión anterior para seguir experimentando.

## Reglas de organización

- Cada idea se añade en una carpeta `prototipos/NNN-nombre/` con `index.html` y su `README.md`.
- El prototipo existente no se sobrescribe para probar un diseño alternativo.
- Las nuevas versiones deben aparecer en el `README.md` raíz y en el índice `index.html`.
- Los recursos importantes deben almacenarse en el repositorio o incorporarse a los archivos HTML.
- Indicar expresamente qué se ha probado y qué es solamente conceptual.

## Concepto 001

**Galería editorial**: composición de columnas verticales que evocan la secuencia rítmica del portfolio de Alan Menken, reinterpretada con moda local. Incluye cambios al pasar el cursor, fichas de cada selección, vista alternativa de cuadrícula, menú y versión táctil. El HTML es autocontenido.

**Limitaciones:** marca y comercios conceptuales, sin funciones comerciales reales ni backend. La inspiración no implica afiliación con Alan Menken.
