# Kuri Fashion · Laboratorio de prototipos

Archivo compartido de experimentos de diseño para **Kuri Fashion**. Cada concepto vive en su propia carpeta: este repositorio no es la tienda en producción.

Los prototipos 001 y 002 son **HTML autocontenidos**. El 008 también se abre directamente en un navegador, pero carga fotografías externas de Unsplash y fuentes remotas. En el 002 los microvídeos son movimientos simulados a partir de fotografías; el 008 utiliza imágenes estáticas, sin fingir vídeo real.

## Método de trabajo: Modo Diseño

1. Referencias visuales y dirección artística.
2. Exploración de conceptos distintivos.
3. Diseño y desarrollo de interacciones.
4. Revisión de escritorio, móvil y accesibilidad básica.
5. Documentación y conservación de cada iteración.

Para un nuevo experimento se crea una carpeta independiente bajo `prototipos/NNN-nombre/`. No se sobrescriben versiones anteriores. La numeración 008 conserva la secuencia de las iteraciones de diseño previas, aunque 003–007 aún no estén archivadas aquí.

## Estado y limitaciones

- **Prototipo ≠ producto final**: sin tiendas reales, inventario, pagos ni logística.
- Imágenes originales generadas para la prueba; historias y nombres de comercios conceptuales.
- Inspiración compositiva en [Alan Menken](https://www.alanmenken.com/), sin utilizar sus imágenes o contenidos.
- Antes de publicar un producto real hay que validar accesibilidad, rendimiento, derechos de contenido y operaciones comerciales.
