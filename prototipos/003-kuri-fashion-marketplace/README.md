# Kuri Fashion · Primer hito

Portada editorial con dos dípticos, acceso a Umbral y Casa Bies, catálogo breve y retorno a Kuri Fashion.

## Ejecutar

Desde este directorio:

```bash
python -m http.server 8000
```

Abrir http://localhost:8000/.

Los cuatro recortes proceden de la lámina conceptual original de fase 1, generada con IA. Los dos archivos MP4 son **simulaciones de movimiento** hechas mediante un desplazamiento suave sobre las fotografías. Son material de demostración para evaluar el hover; no representan vídeo rodado ni productos reales. Los precios y nombres de producto son datos de muestra.

La prueba automática y sus capturas se encuentran en `tests/`.
