# Prototipo 001 — Galería editorial

**Estado:** prototipo visual interactivo.

**Inspiración:** [Alan Menken](https://www.alanmenken.com/) y su composición vertical, reinterpretada para un catálogo editorial de moda independiente.

**Punto de entrada:** [index.html](index.html) — un documento HTML autocontenido, con CSS y JavaScript integrados y fotografía incorporada mediante data URI. Se puede abrir directamente desde el disco sin ejecutar un servidor.

## Interacciones incluidas

- Columnas fotográficas con expansión, variación cromática y desplazamientos.
- Cambio entre vista de tiras y cuadrícula.
- Selección de una historia y navegación entre fichas.
- Menú de pantalla completa.
- Sonido de interacción opcional y control del usuario.
- Diseño adaptable a móvil y gestos táctiles.

## Limitaciones

Es una propuesta de interfaz; las tiendas y relatos son ficticios, y no hay compras, fichas reales, inventario, filtros de producto ni integración con un backend.

## Continuidad

No sustituir este prototipo al diseñar una variante radicalmente distinta. Crear `prototipos/002-...` y añadirla al índice raíz. Los ajustes incrementales a este concepto sí pueden registrarse aquí mediante commits y, cuando corresponda, una rama.
